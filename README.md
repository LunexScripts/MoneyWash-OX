Lunex Scripts presents LX-Moneywash, an advanced and optimized money laundering script for FiveM servers. Originally developed in Dutch, this script provides a realistic and efficient way to launder black money, fully integrated with ox_core and ox_lib, without impacting server performance.

Key Features
- Full ox_core and ox_lib Integration – Seamless compatibility with ox_core.
- Dynamic Money Laundering Locations – Configurable locations for a realistic economy.
- Transaction Management – Customizable laundering percentages and limits for server balance.
- Adjustable Laundering Percentage – The default laundering percentage is set to 65%, but you can change this in the server Lua file.
- Secure Processing – Optimized to prevent abuse or exploits.
- Performance Optimized – Runs at 0.0ms idle, minimal server resource usage.

Requirements
To use this resource, your server must have the following dependencies:

- ox_core: Version 1.0.0 or newer
- ox_lib: Version 3.27.0 or newer
- ox_target
